# FrameDiff example · hero with lower-third

This example opens directly on the complete **HeroWithLowerThird** composition. The separate
[Studio Playground example](../studio-playground) provides the broader guided acceptance project.

Reproduces `lt-marketing/out/hero-with-lower-third/hero-with-lower-third.mp4` (1920×1080 @ 23.976,
1091 frames). The video in `lt-marketing/out/...` is comparison-only; the default composition rebuilds
the hero from cached raw footage imported from `/path/to/raw-footage`. For browser
decode/export, the EDL references cached H.264 proxies generated from those raw files, never the
comparison render.

```
src/compositions/HeroMain.html
├─ data-fd-comp="HeroRaw"           0 → 971    raw footage + recovered AE structure
├─ data-fd-comp="LowerThird"      180 → 348  glass bar and authored frame motion
└─ data-fd-comp="EndCard"         953 → 1091 aurora CTA + shine sting (audio lives in the comp)
```

**HeroRaw** is generated as framework-free HTML in
[src/compositions/HeroRaw.ts](src/compositions/HeroRaw.ts); the physical root composition is
[src/compositions/HeroMain.html](src/compositions/HeroMain.html). The ground
truth is the checked-in After Effects project dump [ae/aep-dump.json](ae/aep-dump.json)
(regenerated by [scripts/ae-dump-project.jsx](scripts/ae-dump-project.jsx));
[scripts/derive-from-aep.ts](scripts/derive-from-aep.ts) distills it into the generated literal
tables in [src/data/heroAep.gen.ts](src/data/heroAep.gen.ts) — still Studio-editable, always regenerable.

- **EDL** ([src/data/heroEdl.ts](src/data/heroEdl.ts)) — cut boundaries and source-ins straight from the
  AEP (visibility-resolved, top-most layer wins; `ceil(in·fps − ε)` boundary rule verified
  against six reference cuts). Real time-stretches: ×0.9 on the open, ×1.2346 on the second
  tripod cut. Where the Desktop raw files are *different re-renders* than the AEP's sources
  (the `latest2*` clips, kling-gerar's earlier internal cut), measured fits from
  [scripts/analysis/fitpane.py](scripts/analysis/fitpane.py) overlay the AEP rows.
- **AE 3D-camera shots**
  ([src/compositions/HeroPlane3D.ts](src/compositions/HeroPlane3D.ts)) — the project maps dumped
  camera rows and fitted curves into the package's `cameraKeyframesFromProgress()` and
  `defineVideoPlane3DComposition()` APIs. The Studio's camera rig panel edits the generated literals live.
- **Grade** ([assets](assets) + [src/effects/luts.ts](src/effects/luts.ts)) — the AEP's `SL GOLD RUSH`
  .itx isn't on disk, so 33³ LUTs were **fitted numerically** from time-aligned (raw, reference)
  frame pairs per shot group (S-Log FX3 vs rec709; PSNR 25–39 dB on held-out pairs).
- **Cards** ([src/compositions/LowerThird.html](src/compositions/LowerThird.html) and
  [src/compositions/EndCard.html](src/compositions/EndCard.html)) — AE text-layer windows/positions with the
  per-character rise, the glass wordmark + the AE template's optical flare (screened).
- **Audio** — the raw music bed + shine/logo-reveal stings, cue frames from the AEP.

The example's [`src/effects/`](src/effects) modules contain only LightTwist configuration and the
remaining branded bumper/split behavior. Generic named-look application, grade serialization,
clip-motion evaluation, wipes, character rises, audio fades, camera-curve expansion, and 3D shot
construction live in the `framediff` package and are imported here.

`?hero=footage` opens the Git LFS-backed legacy AE-rendered hero reference comp. It is not used by
`Main` and should not be treated as an input for the raw rebuild. `?hero=rebuilt` shows the older
proxy-only `HeroRebuilt` comp for comparison.

## Assets

The project selects Git LFS in [`framediff.config.json`](framediff.config.json). All manifest-backed
media and fitted LUTs live in [`assets/`](assets) with readable
`<asset-name>--sha256-<hash>.<ext>` names and are versioned through Git LFS. A fresh checkout only
needs `git lfs pull`; it does not need the original editor's local footage folder.

Some source codecs in the raw folder are not browser-friendly (HEVC, ProRes, and 4:2:2 intra H.264).
Regenerate the raw-derived H.264 proxies with [scripts/make-proxies.sh](scripts/make-proxies.sh), then
run `node scripts/sync-proxies.mjs` to hash them into `assets/` and update the manifest. Those proxies
are derived only from raw footage, never from the comparison render.

## Run

```sh
npm install                                   # repo root
npm run dev --workspace examples/hero-lower-third
# defaults to ?comp=main
# ?comp=hero | hero-raw | lower-third | end-card | hero-script
```

## Dev hooks (used by the compare loop)

- `__renderRange(start, end, name)` — deterministic render of a frame window, saved to `out/<name>`
  via the vite middleware.
- `__probe(compId, frames)` — bake single frames through the real export path to
  `out/probe-<id>-f<N>.png`; score them with `scripts/analysis/compare.py main`.
- `__bake(compId)` — export a nested comp and persist it in **`assets/`** through
  `HttpFolderCAS` (the Git LFS-backed derived-output store; survives reloads, no backend).
- `scripts/analysis/fullcompare.py` — whole-render per-shot PSNR/NCC vs the reference.
  All comparisons pair our frame n with reference frame n+1 (the reference composite samples
  the hero one frame late — measured at six cut boundaries).

## Match status (raw rebuild vs the reference, 2026-07-06)

Whole-video (1090 frame pairs, `scripts/analysis/fullcompare.py`): **21.0 dB PSNR · NCC 0.83 ·
median NCC 0.91** — from raw footage only, no reference pixels used as input.

- Straight cuts sit at NCC 0.94–0.99 (open/phone/desk/blazer/tripod/news/magnific/hf).
- The measured-fit moments land 0.83–0.87 (split, grid wipe, keynote_b, smartest, greentrack).
- The known approximations trail: AE 3D-camera mid-move ease (uizoom 0.92, cam6 0.94, june3d
  0.78, cam4 0.72 — geometry verified exact at the shots' rest frames; the dump lacks per-key
  ease + mask shapes), the code-built bumper/cards, and near-black frames where NCC is noisy.
- Caveat when measuring: the reference is tagged `yuvj420p` **full-range BT.601**, ours is
  limited-range BT.709 — compare in RGB (or per-input `format=rgb24`), never raw YUV. And the
  reference composite samples the hero one frame late (pair ours n ↔ reference n+1).
- What the rebuild exercised in the library: nested comps + trim, `springR`,
  per-frame audio volume, ranged export, backdrop-filter export support, mid-frame sampling —
  and now the **AE import module**, **keyframed 3D video planes** (AE-eased, thin-lens DoF,
  non-16:9 planes), and the **shared capture stand-ins** (a screened flare exported black
  before; probes and exports now composite identically).
